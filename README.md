# 💙 Best Brother Interactive

> A tiny digital Rakhi surprise for a very big brother-sister bond. 🎁✨

An interactive React experience with heartfelt messages, playful animations, memories, music, confetti, and a final celebration made especially for Rakhi. 💫

## ✨ What is inside?

- 🎀 A warm Rakhi welcome and surprise opening
- 💌 A personal letter for your brother
- 📸 A swipeable memory gallery
- 💙 Playful buttons, hearts, sparkles, and sound effects
- 🎉 Confetti, a gift reveal, certificate, and share button
- 📱 Responsive design for laptops and phones

## 🚀 Run it locally

**Requirements:** Node.js 20 LTS or newer.

```bash
npm install
npm run dev
```

Open **http://localhost:3000** in your browser, then click **Open My Surprise**. 🔓

## 📱 Open it on a phone

1. Connect the phone and laptop to the same Wi-Fi.
2. Start the app with `npm run dev`.
3. Find the laptop's IPv4 address with `ipconfig` on Windows.
4. Open `http://YOUR-LAPTOP-IP:3000` on the phone.

Example: `http://192.168.1.25:3000`

Keep the terminal running while the phone is connected. Tap the first button once to enable sound. 🔊

## 🎨 Personalize the Rakhi surprise

The main experience lives in `src/`. Update the words, memories, colors, and interactions in the screen components. Add images or other static files to `assets/`.
